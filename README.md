# Projeto: Análise de Árvores Balanceadas (AVL vs Rubro-Negra)

Este repositório contém a implementação prática e análise comparativa de duas estruturas de dados auto-balanceadas: **Árvore AVL** e **Árvore Rubro-Negra**. O objetivo do projeto é analisar os mecanismos de rotação, recolorização e o impacto dessas abordagens nas operações básicas.

---

## 🛠️ Como Executar o Projeto

### Pré-requisitos
* Ter o Python 3 instalado no computador.
* Nenhuma biblioteca externa é necessária (o programa gera os diagramas do Graphviz em formato de texto puro no terminal).

### Execução
Abra o terminal na pasta do projeto e execute o comando:
```bash
python main.py
